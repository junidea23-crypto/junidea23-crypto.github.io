한눈에 보기

  • 입력한 이름·생년월일·태어난 시각은 내 휴대폰 안에만 저장되고, 개발자 서버로 보내지 않아요. (개발자는 서버를 운영하지 않아요.)
  • 회원가입·로그인이 없어요.
  • 무료 운영을 위해 Google AdMob 광고를 보여 주며, 이 과정에서 Google이 광고 ID 등 기기 정보를 처리해요.
  • 앱을 지우면 앱에 저장된 정보도 모두 지워져요.

1. 처리하는 정보와 목적

앱에 직접 입력하는 정보이름(한글·한자), 성별, 생년월일(양력·음력), 태어난 시각, 궁합 상대의 이름·생년월일(선택)
목적: 사주·이름 풀이와 궁합 결과 계산
저장 위치: 사용자 휴대폰 내부 저장소에만 저장 (외부 전송 없음)
앱 이용 기록출석 도장, 미션 체크, 광고 제거권 개수, 알림 설정 시각
목적: 이벤트 보상과 설정 유지
저장 위치: 사용자 휴대폰 내부에만 저장
광고 관련 정보 (Google이 처리)광고 ID, 기기 및 앱 정보, IP 주소로 추정한 대략적 위치, 광고 표시·클릭 기록, 오류·성능 정보
목적: 광고 표시, 광고 성과 측정, 부정 클릭 방지

개발자는 위 정보 중 어떤 것도 직접 받거나 보관하지 않아요.

2. 외부 서비스(처리 위탁 및 제3자 제공)

Google AdMob
(Google LLC)		배너·전면·보상형 광고 제공. 광고 ID 등 위 1번의 광고 관련 정보를 Google이 수집·처리해요. 유럽 등 법으로 동의가 필요한 지역에서는 앱을 처음 열 때 동의 창이 나와요.
Google 개인정보처리방침 · Google의 광고 정보 사용 방식
Google Fonts화면 글꼴을 불러올 때 휴대폰의 IP 주소가 Google 서버에 전달될 수 있어요.
공유 기능요정 카드·궁합 결과를 공유하면, 사용자가 직접 고른 앱(카카오톡, 인스타그램, 갤러리 등)으로 이미지와 문구가 전달돼요. 공유하지 않으면 아무것도 전달되지 않아요.

개발자는 사용자의 개인정보를 판매하거나 위 목적 외로 제3자에게 제공하지 않아요.

3. 보유 기간과 삭제 방법

  • 앱에 입력한 정보는 사용자가 지우기 전까지 휴대폰에 남아 있어요.
  • 삭제 방법: 앱 삭제, 또는 휴대폰 설정 → 애플리케이션 → 달빛 사주관 → 저장공간 → 데이터 삭제. 즉시 완전히 지워져요.
  • Google이 처리하는 광고 정보의 보관 기간은 Google 정책을 따라요.

4. 맞춤 광고 끄기

  • 안드로이드: 휴대폰 설정 → Google → 모든 서비스 → 광고 → 광고 ID 삭제 (기종마다 메뉴 이름이 조금 다를 수 있어요)
  • 광고 동의가 필요한 지역에서는 앱의 마이 → 광고 개인정보 설정에서 언제든 다시 선택할 수 있어요.

5. 알림

'아침 운세 알림'을 켜면 휴대폰 안에서 알림이 예약돼요. 알림 내용은 휴대폰에서 만들어지며 외부로 보내지 않아요. 휴대폰 설정에서 언제든 끌 수 있어요.

6. 아동의 개인정보

이 앱은 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 알면서 수집하지 않아요.

7. 이용자의 권리

모든 정보가 사용자 휴대폰에 있으므로, 사용자는 앱에서 언제든 정보를 확인·수정(마이 → 내 정보)하거나 위 3번 방법으로 삭제할 수 있어요. 궁금한 점은 아래 문의처로 연락해 주세요.

8. 안전성 확보 조치

정보를 서버로 보내지 않고 휴대폰 안의 앱 전용 저장 공간에만 보관해 다른 앱이 읽을 수 없도록 해요. 광고 통신은 암호화(HTTPS)된 연결로 이루어져요.
